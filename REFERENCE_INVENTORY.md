## Source content and behavior

- Eight pages: `index.html`, `about.html`, `service.html`, `price.html`, `team.html`, `testimonial.html`, `appointment.html`, `contact.html`.
- `index.html` contains the shared clinic page layout: spinner/preloader, contact strip, sticky responsive navbar, search modal, hero carousel, three-card banner, about, appointment, services, offer, pricing carousel, before/after comparison, team, testimonials, newsletter/contact elements, footer, and back-to-top control.
- `js/main.js` initializes the spinner, WOW.js animations, sticky navbar, hover dropdowns, back-to-top, date/time picker, image comparison, and Owl Carousel price/testimonial controls.
- Libraries are Bootstrap 5 CSS (vendored minified plus SCSS source), Owl Carousel, Animate.css, Easing, Tempus Dominus, TwentyTwenty, Waypoints, and WOW.js. HTML pages load Bootstrap JS and jQuery from external CDNs.
- Twenty source JPGs are in `img/`; one source GIF and one PNG are in the library assets. These dental-template photos are not used in the Raphael product.
